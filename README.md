# Document Dependency Graphs (DDG)

A local, isolated audit workbench that builds a persistent, evidence-bearing dependency graph
across a narrative report and its Excel model, and keeps that graph honest through revisions.

**Status:** planning complete, implementation not started.

See **[PROJECT_PLAN.md](PROJECT_PLAN.md)** for scope, architecture, data model, safety rules,
evaluation design, toolchain, milestones and required inputs.
