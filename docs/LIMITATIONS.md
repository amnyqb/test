# Limitations

## No empirical claim is supported yet

Every result to date comes from **synthetic fixtures** generated by
`tests/fixtures/make_fixtures.py`, each marked `SYNTHETIC FIXTURE` in its own text.
They test arithmetic, anchoring and gate behaviour. They are not a corpus.

Nothing here supports a figure for semantic precision (S02), recall (S03), defect
recall (S05) or analyst effort (S08). Those require authorised real sources, a
held-out split of at least 200 semantic relations, and an independent adjudicator.

## Known gaps in the implementation

- **Formula evaluation.** `openpyxl` does not evaluate formulas, and a workbook
  written by `openpyxl` carries no cached results at all — so formula cells report
  `NOT_CHECKED`. This is correct abstention, not a passing audit. A real workbook
  saved by Excel does carry cached values, which are read and explicitly flagged
  as cached. A trusted evaluator remains future work, pending a compatibility test.
- **PDF anchoring** stores a single word's bounding box per line, not a full region.
- **Quantity context** is authored by a reviewer in `review.json`. Recovering it
  automatically is Milestone 2's job.
- **Narrative quantity extraction** is a deterministic regex requiring a currency
  marker, scale word or decimal separator. It will miss quantities written in words
  ("twelve point four million") and any unit vocabulary beyond currency.
- **No revision engine yet.** `anchors.remap` is implemented and tested, but closure
  invalidation, stale-before-publish and audit replay are not.
- **No UI.** Findings render to the terminal; the evidence viewer is not built.

## Safety scope

The injection fixture proves that document text demanding a `PASS` does not get one
through the deterministic path. That result does **not** extend to the LLM path,
which does not exist yet and must be tested separately once it does.
